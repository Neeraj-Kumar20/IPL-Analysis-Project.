# IPL Data Analysis Project

A Python-based project that analyzes historical IPL match data. The goal of this project is to derive insights into match trends, team performance, and player statistics.

## Key Features:
* Season-wise match analysis.
* Team and player performance insights.

## How to Run:
python ipl_project.py

## Tools Used:
Python, Pandas, VS Code.
